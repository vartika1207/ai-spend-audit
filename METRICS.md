# Metrics

The North Star metric is qualified savings discovered per week. This fits the product better than DAU because the tool is not meant to be used daily. It should create one valuable moment: a founder or engineering manager sees credible savings and decides whether to act.

Three input metrics drive the North Star. First, audit completion rate: if users abandon the form, the tool is too complex. Second, median monthly savings found: if this is too low, the target audience or audit rules are wrong. Third, high-savings lead capture rate: if users see large savings but do not share email, the report is not trusted enough.

I would instrument: landing page view, start audit, add tool, complete audit, copy/share URL, email captured, consultation CTA clicked, and email delivered. I would also track source channel so GTM experiments can be compared.

A pivot trigger would be 200 completed audits with less than 5% producing over $500/month savings. That would mean either the target segment does not have the pain, the rules are too conservative, or the tool is reaching the wrong audience. Another trigger would be high savings but below 10% email capture, which would point to a trust or positioning problem.
