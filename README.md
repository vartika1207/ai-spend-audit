# SpendScope — AI Spend Audit

SpendScope is a free web app for startup founders and engineering managers to audit AI-tool spend across Cursor, GitHub Copilot, Claude, ChatGPT, Gemini, APIs, and v0. It gives an instant savings report, captures leads only after value is shown, and creates a shareable public URL.

## Quick start
```bash
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## Deploy
Deploy to Vercel. Add environment variables from `.env.example`. Supabase is optional for local demos but required for persistent public audit URLs in production.

## Database schema
```sql
create table audits (
  id text primary key,
  payload jsonb not null,
  created_at timestamptz default now()
);

create table leads (
  id bigint generated by default as identity primary key,
  auditId text,
  email text not null,
  companyName text,
  role text,
  teamSize int,
  monthlySavings numeric,
  high_savings boolean,
  created_at timestamptz default now()
);
```

## Decisions
1. I used Next.js because it gives frontend, API routes, SEO metadata, and deployment in one stack.
2. I kept audit math deterministic instead of LLM-generated because financial recommendations need repeatable reasoning.
3. I used localStorage for form persistence because the project requires no login before value is shown.
4. I used Supabase with an in-memory fallback so the app can run locally without setup but still has real production storage.
5. I used a honeypot field for basic abuse protection because it is frictionless for legitimate users.
